# 作者编辑与目录版本 3


作者页使用独立入口，不读取或修改聊天进度。调用链为页面 → 作者用例 → 领域规则 → 草稿存储端口 → 账号文件适配器。草稿仍为 manifest/catalog/layouts/theme/assets 分文件目录；author.json 只保存修订随机标记、来源及待确认分支 ID，不保存内容镜像。接口修订号是这些文件的内容摘要，直接修改文件也会使旧修订失效。

目录版本 2 保留读取及运行行为。新目录版本 3 的每个成就节点必须有 dependencies 数组，禁止同时写 prerequisiteNodeIds。kind=branch 最多一个，必须同树；kind=prerequisite 允许跨树及跨模块。所有前置引用具体成就节点，全部完成才满足前置。两类关系一起查环，强依赖单独决定分支删除。没有强父的首节点通过树归属连接到结构入口；入口不参与完成依赖。怪物仍以 rootNodeId 指向初见成就；旧剧情 rootNodeId 格式保留读取。

旧稿转换只把原引用标为 prerequisite，pendingBranchNodeIds 记录待作者确认的节点。作者必须明确选定父节点或确认起点，不按旧线条猜父子。确认前禁止级联删除及发布。

节点 description 保存作者给用户看的文案；生成附言仍属于聊天。剧情成就由 AI 判断，直接记入达成事实，无需接取或领取。其他版本 3 节点继续使用已有五态任务规则。结果应用统一检查前置、互斥及阶段，剧情额外前置不能消费本批模型提案。怪物根的任务入口在前置满足后可打开、接取，介绍仍在完成后展示。版本 2 的初见及同批怪物规则保持兼容。

布局新增 hiddenBranchNodeIds（隐藏该节点的父子线）及 visualEdges（from/to/routing/points）；纯视觉线不改变依赖。第一版支持曲线、直角折线及单个控制点。拖动和自动整理只改布局，隐藏状态在保存重开后保留。图引擎数据不是领域真源。

每次编辑只改变结构化工作副本，保存才整稿提交。删除节点及全部强后代，保留外部前置引用，节点旁标红并列出缺失 ID。草稿允许空名称、空条件及失效引用；发布使用严格校验。自指、环、重复引用、跨树强父和多个强父在编辑时拒绝。

同账号同包写入用最小互斥和修订检查，忙碌或旧修订直接报告冲突，不接入玩家队列。文件适配器以暂存目录、恢复目录和重命名提交完整草稿；读取同样经过互斥，失败恢复旧稿，崩溃后先恢复再读取。发布预检绑定草稿修订及完整文件指纹，发布复用已有不可覆盖发布器。

资产使用约定 ID 路径，只扫描草稿 assets 下的安全图片，刷新登记并绑定对应槽位；没有文件使用占位，缺失已引用资源阻止发布。预览资源使用账号检查和 no-store。所有路径校验真实路径，拒绝符号链接越界。

作者入口支持创建新包、从同账号 release 复制为草稿、保存、刷新资产、预检、发布。发布与角色卡绑定是不同操作，绑定仍通过现有版本入口。旅行与日记作者页面暂缓。

版本 3 从本地目录及进度提供基础 canSend，不要求 MVU、Amily 或世界书。技能所属者的 revealNodeId 由本地进度检查；可选外部白名单仍能收紧准入。版本 2 保留显式外部白名单行为。

复制旧发布包时生成来源版本和哈希明确的身份映射；删除作者节点时把对应迁移目标设为 null。发布仍不升级任何聊天。显式升级 2 → 3 可保留已完成记录及私人文字，后续新节点按五态运行；不能借格式升级跨模块或改变 skill/combat 类型。旧节点的强父选择仍须作者确认。旅行的独立作者页暂缓，问题列表只提供既有旅行节点前置的确认与修复。

图片读取允许并行；同稿写入仍互斥，冲突直接报告。发布在暂存完整包验证后再次核对源稿及资源指纹，源稿变化时不安装该 release。新代码部署前不得把版本 3 包绑定给只支持版本 2 的旧客户端。

## 剧情卡片与隐藏入口（2026-10-11 修订）

用户确认的层级如下：

```text
剧情阶段二〔一张卡片，点击进入〕
├─ 示例地区〔剧情树卡片〕
└─ 碧湖港〔剧情树卡片，点击进入画布〕
   └─ 暗主节点〔建树时自动建立的隐藏入口〕
      └─ 初来碧湖港〔玩家可见的首个成就〕
         └─ 办理证明〔后续成就〕
```

暗主节点只代表整树入口。新剧情树保存 entryNodeId，入口布局保存于本树 positions；它不在 nodes 中，不拥有 condition、dependencies 或进度，不作为候选发送，不统计成就。无强父的本树成就隐式隶属于入口，这个归属来自 storyTreeId。作者画布显示入口，可右键编辑树资料或新建子节点；玩家视图只显示成就。

keywords 只保存于剧情树，入口与树卡片编辑同一份资料。普通节点仅保留图片、名称、完成判定条件、给用户的话和前置依赖，没有节点触发词。输入字段的深度改版及星空美术留到后续。

剧情阶段通过卡片进入，其内部仅列本阶段剧情树卡片。树卡片进入画布，提供返回阶段和返回模块的导航。其他模块沿各自归属层级进入，避免平铺所有实体。

版本 3 剧情按当前阶段和树关键词粗筛，命中后发送本树全部成就、依赖与完成状态，不以接取状态或尚未满足的前置裁剪树。外部白名单必须授权整树所有节点及互斥组，否则整树不发送，避免部分泄露或错误声明已满足外部前置。跨树前置仍由本地进度审核，模型看到后续节点不能跳过依赖。

新建树同时生成入口；空树结构有效。加载旧作者草稿时补入口并移除旧剧情 rootNodeId，仅修改工作副本，保留所有成就 ID、文案、图片及依赖。保存后再提交转换结果；发布包和聊天不自动改写。

阶段和树提供删除预览，整棵移除所属树、成就、布局、剧情线与互斥组；其他实体对被删节点或阶段的引用保留并诊断。剩余阶段编号连续重排，迁移映射将被删节点和阶段明确设为 null。一次删除作为一个作者命令，可完整撤销和重做。
