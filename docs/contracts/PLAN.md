# 通用产品规则

七栏目为冒险、人物羁绊、职业、技艺、知识、旅行、日记。剧情按显式当前章节选材；人物与战斗树按归属关键词匹配；职业、技能、知识仅发送已接取的 active 任务。

成长任务采用 `blocked → available → active → claimable → completed`。模型判定转为可领取，玩家领取后才完成。依赖规则由数据层统一处理，跨模块依赖参与状态计算，展示层不输出跨页连线。

每个人物、职业、技能持有者可以从卡片入口进入独立树，返回后恢复原入口焦点。尚未遇见的人物入口隐藏。普通滚轮滚动，Ctrl+滚轮缩放，中键平移。

模型结果每个请求每个模块至多一条更新；请求身份和版本由程序加戳。保留请求防重复与在途版本保护。新记录不保存正文来源，旧存档迁移保留历史字段。

章节完成统计、地点统计和账号内容/图片自动部署尚未实现。具体内容、人物外观、树节点与坐标由独立私有内容包定义。
