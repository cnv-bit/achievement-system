# 使用作者编辑器

酒馆助手脚本增加“成就卡带编辑器”按钮，独立于玩家手账。它可以在没有已加载角色卡内容包时打开。

1. 新建卡带，或输入本账号已有发布包的 ID 和版本来复制。已有草稿会拒绝覆盖。
2. 从左侧选择模块，点击卡片逐层进入。剧情：阶段卡片 → 所属剧情树卡片 → 树画布；技能：所属者 → 技能树；知识：领域 → 主题。人物、职业直接建卡。新建怪物同时建图鉴条目及初见节点。
3. 新剧情树自动出现隐藏入口。右键入口选择“编辑整树资料与关键词”或“新建子节点”；创建“初来碧湖港”后，右键这个成就继续创建“办理证明”。其他空树使用“创建首个节点”。左键查看，右键编辑。普通成就填写名称、给用户的话、供 AI 判断的完成条件、图片说明和额外前置；没有单独触发词。额外前置可以搜索名称、模块、树或 ID，并用勾选添加。
4. 左键拖动节点；Alt 加方向键可微调。怪物保持固定布局。“自动整理”只改位置。右键的“线条外观”可永久隐藏父子线、增加或移除视觉线；拖动圆形控制点调整视觉线。
5. 保存草稿后，放置规定路径的图片并刷新资产；预检通过后发布新版本。再通过已有“内容版本”页面应用到角色卡，或显式升级旧聊天。

F2 编辑节点，Shift+F10 打开菜单；菜单支持上下方向键。Ctrl+S 保存，Ctrl+Z 撤销，Ctrl+Shift+Z 重做。关闭或换稿时，未保存内容会提示。

草稿目录为当前账号的 `goblin-achievements/packs/<packId>/draft/`，位于酒馆账号数据根下。图片字段展示准确的包内路径，可复制；默认槽位为 WebP。改名称不会改变稳定 ID 或图片路径。页面不上传文件，不打开文件选择器。缺图显示文字占位，已引用资源丢失会阻止发布。

剧情、人物及怪物在树资料中设置关键词，目前每行一个，支持普通文本和 /正则/flags。版本 3 剧情按当前阶段与关键词粗筛，命中后整树发送，包含未完成后续及完成状态；无需接取或领取，前置审核仍在结果写入时执行。其他版本 3 节点沿用五态任务规则。职业、技能和知识的 active 任务沿用主动任务选材。基础流程不依赖特定变量或世界书；给用户的话不作为模型判定材料。

隐藏入口属于树资料与布局，没有完成条件、前置、玩家进度或成就计数。玩家页面隐藏它；作者可以拖动它，编辑同一份整树关键词。旧草稿打开后在工作副本中补充入口，原成就 ID、文字、图片、依赖和位置保留，保存才提交转换。原有节点阶段覆盖作为兼容资料保留；若引用阶段被删除，可在节点表单勾选清除。

删除分支会删除节点及其强后代。其他引用节点保留，旁边标红并列出失效 ID；后续受影响节点也标红。草稿可以保存这种状态，修复前不能发布。删除不会改任何聊天进度。

阶段和剧情树卡片的右键菜单，以及进入后的资料页，均有删除入口。确认窗口列出所属树和成就；删除阶段同时删除内部树，其他树的引用保留。一次删除可完整撤销或重做。剩余阶段编号自动整理。

复制版本 2 后，有旧前置的节点需要逐个确认强父节点或起点身份。不要按线条外观猜父子。确认前禁止级联删除和发布；旧旅行节点只提供前置修复，地图和日记作者页面尚未提供。

保存提交整份草稿。保存失败保留旧稿及页面工作副本；旧修订提交会报冲突。请保留旧页资料再核对最新稿，页面不会自动覆盖它。发布版本不可覆盖，预检后内容或资源变化要重新预检。
